# Sognefjord Adventure Tours — Logo Package

Chosen direction: **Fjord Cut** — a minimalist peak-and-water mark with restrained amber horizon detail.

Palette:
- Fjord Teal: #0B3D46
- Deep Fjord Blue: #082F3A
- Moss Green: #3F5F4B
- Golden Amber: #D69A2D
- Snow White: #F7F4EC
- Charcoal: #111416

Typeface recommendation: Söhne or GT America for the wordmark; Inter is the practical open-source fallback. For taglines, use Canela/Tiempos or Libre Baskerville fallback.

Files included cover primary/secondary/icon/favicon/monochrome/inverted/social/avatar/brand sheet. SVG files are vector source files; PNG files are production previews/exports.
